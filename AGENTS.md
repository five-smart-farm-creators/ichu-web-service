# Agent Instructions

These instructions apply to agents working on the ICHU backend. Read and follow [CONTRIBUTING.md](CONTRIBUTING.md) for project structure, DDD boundaries, English-only content, code quality, reuse, naming, comments, Git Flow, Conventional Commits, and review requirements.

Before editing, check the current branch and working tree, preserve existing changes, and read any more specific `AGENTS.md` files along the affected path.

Reuse existing capabilities when they fit and respect the project's context boundaries. Do not introduce new directories, tooling, dependencies, or architectural layers unless requested by the user or explicitly required by the authorized task.

Do not create branches, commits, pushes, pull requests, merges, or delete branches unless the user asks. Keep changes within the requested scope.

Use existing project checks appropriate to the change, avoid adding test infrastructure without a request, and report only verification actually performed.
